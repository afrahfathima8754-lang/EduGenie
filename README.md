# EduGenie

## Google Gemini Powered Learning Assistant

EduGenie is a learning assistant that helps students understand topics, ask questions, get explanations, create summaries, and follow a learning path.

## Features

- Question and Answer
- Topic Explanation
- Summary Generation
- Personalized Learning Path

## Technologies Used

- Python
- Google Gemini API
- HTML
- CSS

## Project Files

- main.py
- qna.py
- explanation_module.py
- summary_module.py
- learning_path.py
- index.html
- style.css
