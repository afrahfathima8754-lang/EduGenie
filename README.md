EduGenie 🎓

EduGenie is an AI-powered educational assistant built with Python, HTML/CSS, and Google Gemini. It helps students with interactive Q&A, detailed explanations, personalized learning paths, and content summarization.

---

🚀 Features

- Interactive Q&A ("qna.py") – Answers academic questions using AI.
- Detailed Explanations ("explanation_module.py") – Provides easy-to-understand explanations.
- Structured Learning Paths ("learning_path.py") – Creates step-by-step learning paths.
- Content Summarization ("summary_module.py") – Generates concise summaries for study materials.

💻 Getting Started

1. Prerequisites

Make sure Python 3.8 or higher is installed on your computer.

2. Install Dependencies

Clone the repository:

git clone https://github.com/afrahfathima8754-lang/EduGenie.git

Go to the project folder:

cd EduGenie

Install the required packages:

pip install -r requirements.txt

3. API Key Setup

Create a ".env" file in the project folder and add your Google Gemini API key:

GEMINI_API_KEY=your_gemini_api_key_here

Do not upload or share your real API key publicly.

4. Run the Application

python main.py
